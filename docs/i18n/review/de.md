## Patterns

- **Percent spacing:** #455, #458 and #1000 copy the Hungarian `{pct}%` without the space that STYLE requires for German. All other % in the German catalog already have the space, so these are three copy errors, not a system problem.
- **Plurals:** no catalog extract has any `.one` key. The five German `.other` keys (#539, #602, #640, #1002, #1052) give "1 Bilder", "1 Routen" and "1 frühere Fahrten" at count 1, and count placeholders next to plural nouns (#977 "{} Fahrten", #984 "{n} Fahrten") have the same gap. STYLE requires both `.one` and `.other` in every language, so the extractor or the catalogs need the `.one` rows.
- **Sentence fragments:** the about dialog and settings build sentences from separate lowercase keys (#466, #470, #473, #625, #586). CLAUDE.md forbids building sentences from fragments; these need one key per full sentence. #586 is also the only leading-space mismatch found.
- **Glossary drift:** the "Rennynamik" typo sits in GLOSSARY.tsv (versenydinamika, de column) and in #348. The review page uses "edzés" for recorded rides (#84, #917, #927–#931, #934, #953); German says "Fahrt", which is right by meaning, but the glossary defines edzés only as Workout. Also "übrig" (glossary) vs "Rest/Restzeit" (#773, #774), and "Teilen" (#675) vs "Freigabe" (#698) for the same button.
- **Units and wording:** the time abbreviations "Std." (#293) and "Min." (#300) differ from the "h" and "min" used in the app's format strings, and "Zielwatt" appears with a singular article and plural verb (#22, #705). The hyphenated "Street-View-" compounds (about 10 rows, e.g. #29, #629, #1057) are standard German, but they differ from the brand form "Street View" that STYLE asks to keep; decide once and apply everywhere.
